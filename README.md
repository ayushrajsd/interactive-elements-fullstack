# interactive-elements-fullstack

A lightweight starter web app for teaching difficult full-stack concepts using visual, animated, interactive explainers.

## Current concept
- **How the Web Works** (request lifecycle + browser rendering pipeline).

## Run locally
Open `index.html` in a browser.

## Teaching layout
- **Left side:** the main flow timeline.
- **Right side:** details for the current step.
- Includes controls for start/pause/next/reset and speed.
